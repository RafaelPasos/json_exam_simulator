About JSON Exam Simulator

This is a lightweight, fully local web app designed to simulate certification exams using custom JSON files. Your data never leaves your browser.

How to Use

Click a preloaded exam or drag-and-drop your own JSON file. Adjust the settings, and click Start Exam.

JSON Format Example

{
  "title": "Example Certification Exam",
  "questions": [
    {
      "id": 1,
      "question": "What does JSON stand for?",
    "options": [
      "Java Standard Output Network", 
      "JavaScript Object Notation"
    ],
    "answer": 1,
      "justification": "JSON is a lightweight format."
    }
  ]
}
